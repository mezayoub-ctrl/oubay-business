# OUBAY BUSINESS — النسخة التجريبية الأولى

## الملفات
- `index.html`: واجهة التطبيق العربية.
- `style.css`: التصميم المتجاوب والألوان.
- `app.js`: إدارة السجلات والتخزين المحلي والنسخ الاحتياطي.
- `manifest.webmanifest`: إعدادات التثبيت كتطبيق ويب.
- `sw.js`: التخزين المؤقت للعمل بعد أول تحميل.

## المزايا الحالية
- تسجيل المصانع والموردين وتجار الجملة، وتجار التجزئة، والسائقين.
- تصنيف النشاط الغذائي.
- حفظ محلي باستخدام IndexedDB.
- البحث والتصفية والتعديل والحذف.
- تمييز التعامل بالدين.
- تصدير واسترجاع نسخة JSON احتياطية.
- إعدادات أولية لتثبيت PWA والعمل بعد أول تحميل.

## التشغيل
يجب نشر الملفات على استضافة HTTPS حتى تعمل ميزات PWA وService Worker بصورة صحيحة. يمكن استخدام GitHub Pages من مستودع GitHub.
هذه نسخة أولية وليست نظامًا محاسبيًا متكاملًا؛ لا تحتوي بعد على المبيعات والمشتريات والمخزون وتسديد الديون والتقارير المالية.
